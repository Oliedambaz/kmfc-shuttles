# KMFC Shuttles Website

A responsive static website for KMFC Shuttles — Cape Town Airport Transfers & Tours.

## GitHub Pages

1. Create a GitHub repository, e.g. `kmfc-shuttles`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide your website URL.

## Before publishing

Edit `script.js` and replace `27746889682` with the business WhatsApp number in international format.

Also replace the placeholder phone number and email address in `index.html`.
